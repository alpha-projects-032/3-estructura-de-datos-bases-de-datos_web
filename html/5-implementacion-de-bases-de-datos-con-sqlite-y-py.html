Implementación de bases de datos con SQLite y Python

Crear, administrar y consultar bases de datos persistentes utilizando SQLite, Python y operaciones CRUD.

Objetivo de aprendizaje

Implementar bases de datos relacionales utilizando SQLite y Python, mediante la creación de conexiones, definición de tablas, inserción, consulta, actualización y eliminación de registros, aplicando las operaciones CRUD y mecanismos básicos de gestión de transacciones, para desarrollar soluciones que permitan almacenar y administrar información de manera persistente y estructurada.

Introducción

En los subtemas anteriores se estudiaron los fundamentos de las bases de datos, sus mecanismos de organización, los principales modelos de almacenamiento y las operaciones CRUD utilizadas para administrar información.

Estos conocimientos permiten comprender que una base de datos no solamente almacena registros, sino que también utiliza estructuras y algoritmos especializados para organizar, relacionar y recuperar datos.

En el desarrollo de software con Python, es posible trabajar con diferentes sistemas gestores de bases de datos. Uno de los más accesibles para comenzar es SQLite, debido a que permite crear y administrar bases de datos sin instalar un servidor independiente.

SQLite es especialmente útil para aplicaciones locales, prototipos, herramientas educativas y sistemas que necesitan almacenar información de manera persistente.

Python incorpora el módulo sqlite3, que proporciona una interfaz para establecer conexiones, ejecutar instrucciones SQL y recuperar resultados.

En este subtema se desarrollará una implementación progresiva, comenzando por la creación de una base de datos hasta la construcción de un sistema sencillo de administración de estudiantes.

5.1. Introducción a SQLite como sistema de gestión de bases de datos

SQLite es un motor de bases de datos relacional que permite almacenar y administrar información mediante SQL, sin requerir un servidor independiente.

SQLite se integra con las aplicaciones y normalmente almacena la información persistente en un archivo que contiene tablas, registros, índices y otras estructuras de almacenamiento.

Características principales

Característica Descripción
Motor integrado Se ejecuta dentro de la aplicación.
Sin servidor independiente No requiere administrar un servidor específico.
Persistencia Puede conservar registros en un archivo local.
SQL Permite crear tablas, consultar y modificar datos.
Transacciones Permite confirmar o revertir operaciones.
Portabilidad Los archivos pueden utilizarse en diferentes sistemas compatibles.
Integración con Python Disponible mediante el módulo sqlite3.

Relación con las estructuras de datos

SQLite utiliza estructuras como árboles B para organizar internamente las tablas y los índices en bases de datos ordinarias. Estas estructuras contribuyen a las operaciones de búsqueda, inserción y eliminación.

Mientras el usuario trabaja con tablas y registros, el motor administra las estructuras físicas necesarias para almacenar y recuperar la información.

Aplicaciones de SQLite

Aplicaciones de escritorio

Almacenamiento local de información y configuraciones.

Sistemas de inventario

SQLite también se utiliza en aplicaciones móviles. Su conveniencia depende de las necesidades de concurrencia, arquitectura y funcionamiento de cada sistema.

5.3. Introducción al módulo sqlite3

El módulo sqlite3 permite establecer conexiones, ejecutar instrucciones SQL, recuperar resultados y controlar transacciones.

Importación del módulo

import sqlite3

Componentes principales

Componente Función
sqlite3.connect() Establecer conexión.
connection.execute() Ejecutar SQL desde la conexión.
connection.cursor() Crear un cursor.
cursor.execute() Ejecutar una instrucción SQL.
cursor.fetchone() Recuperar una fila.
cursor.fetchall() Recuperar las filas restantes.
connection.commit() Confirmar cambios pendientes.
connection.rollback() Revertir cambios no confirmados.
connection.close() Cerrar la conexión.

cursor = conexion.cursor()

Administra el acceso a la base de datos y las transacciones.

Cursor

También es posible ejecutar SQL mediante conexion.execute(), que crea un cursor de forma implícita.

5.4. Creación de una base de datos desde Python

Para comenzar a utilizar SQLite se establece una conexión con un archivo. Si este no existe, SQLite normalmente lo crea.

Paso 1. Importar sqlite3

import sqlite3

Paso 2. Crear la conexión

conexion = sqlite3.connect("universidad.db")

Paso 3. Crear un cursor

cursor = conexion.cursor()

Paso 4. Cerrar la conexión

conexion.close()

Código completo

import sqlite3

# Crear o abrir la base de datos
conexion = sqlite3.connect("universidad.db")

# Crear cursor
cursor = conexion.cursor()

print("Base de datos preparada correctamente")

# Cerrar conexión
conexion.close()
Resultado 
Base de datos preparada correctamente

Explicación del proceso

  1. Python importa el módulo SQLite.
  2. Establece una conexión con el archivo indicado.
  3. Crea un cursor para realizar operaciones.
  4. Muestra un mensaje de confirmación.
  5. Cierra la conexión.

En este momento no se han creado tablas. El archivo universidad.db prepara el almacenamiento para las siguientes operaciones.

5.5. Creación de tablas y definición de campos

Una vez creada la base de datos se definen las tablas que almacenarán los registros, mediante la instrucción CREATE TABLE.

Estructura de la tabla estudiantes

Campo Tipo Restricción
id_estudiante INTEGER PRIMARY KEY
nombre TEXT NOT NULL
carrera TEXT NOT NULL
edad INTEGER Sin restricción adicional

Creación mediante SQL

CREATE TABLE estudiantes (
    id_estudiante INTEGER PRIMARY KEY,
    nombre TEXT NOT NULL,
    carrera TEXT NOT NULL,
    edad INTEGER
);

Creación mediante Python

import sqlite3

conexion = sqlite3.connect("universidad.db")

cursor = conexion.cursor()

cursor.execute("""
    CREATE TABLE IF NOT EXISTS estudiantes (
        id_estudiante INTEGER PRIMARY KEY,
        nombre TEXT NOT NULL,
        carrera TEXT NOT NULL,
        edad INTEGER
    )
""")

conexion.commit()

print("Tabla creada correctamente")

conexion.close()
Resultado 
Tabla creada correctamente

Explicación

  • CREATE TABLE crea la tabla.
  • IF NOT EXISTS evita el error si la tabla ya existe, pero no modifica su estructura.
  • INTEGER PRIMARY KEY define el identificador entero.
  • TEXT NOT NULL exige un valor no nulo.
  • commit() confirma los cambios pendientes cuando corresponde.

Restricciones adicionales

CREATE TABLE IF NOT EXISTS productos (
    id_producto INTEGER PRIMARY KEY,
    nombre TEXT NOT NULL,
    codigo TEXT UNIQUE,
    precio REAL CHECK(precio >= 0),
    existencia INTEGER CHECK(existencia >= 0)
);

UNIQUE impide valores duplicados no nulos y CHECK establece condiciones sobre los valores. Estas restricciones contribuyen a mantener la integridad de la información.

5.6. Inserción y consulta de registros mediante Python

Las operaciones Create y Read permiten incorporar y recuperar registros de una base de datos.

Inserción de un registro

import sqlite3

conexion = sqlite3.connect("universidad.db")
cursor = conexion.cursor()

cursor.execute("""
    INSERT INTO estudiantes
    (nombre, carrera, edad)
    VALUES (?, ?, ?)
""", ("Ana Martínez", "Desarrollo de Software", 20))

conexion.commit()

print("Estudiante registrado")

conexion.close()

Los marcadores ? representan parámetros. Los valores se envían por separado y se asocian según su orden, lo que contribuye a prevenir inyecciones SQL.

Inserción de varios registros con executemany()

import sqlite3

conexion = sqlite3.connect("universidad.db")
cursor = conexion.cursor()

estudiantes = [
    ("Carlos López", "Redes Informáticas", 22),
    ("María Hernández", "Desarrollo de Software", 21),
    ("José Ramírez", "Ciberseguridad", 23)
]

cursor.executemany("""
    INSERT INTO estudiantes
    (nombre, carrera, edad)
    VALUES (?, ?, ?)
""", estudiantes)

conexion.commit()

print("Registros insertados correctamente")

conexion.close()

La lista contiene tuplas de estudiantes. executemany() ejecuta la misma instrucción utilizando cada conjunto de valores.

Consulta de todos los registros

import sqlite3

conexion = sqlite3.connect("universidad.db")
cursor = conexion.cursor()

cursor.execute(
    "SELECT * FROM estudiantes ORDER BY id_estudiante"
)

registros = cursor.fetchall()

for estudiante in registros:
    print(estudiante)

conexion.close()
Resultado esperado en una base inicialmente vacía 
(1, 'Ana Martínez', 'Desarrollo de Software', 20)
(2, 'Carlos López', 'Redes Informáticas', 22)
(3, 'María Hernández', 'Desarrollo de Software', 21)
(4, 'José Ramírez', 'Ciberseguridad', 23)

Los identificadores y resultados pueden cambiar si el archivo contiene registros previos o si se ejecutaron varias veces los ejemplos.

Consulta mediante condiciones

import sqlite3

conexion = sqlite3.connect("universidad.db")
cursor = conexion.cursor()

cursor.execute("""
    SELECT nombre, edad
    FROM estudiantes
    WHERE carrera = ?
    ORDER BY nombre
""", ("Desarrollo de Software",))

resultados = cursor.fetchall()

for estudiante in resultados:
    print(estudiante)

conexion.close()
Resultado esperado 
('Ana Martínez', 20)
('María Hernández', 21)

fetchone() y fetchall()

fetchone()

Recupera la siguiente fila disponible, o None si no hay resultados restantes.

fetchall()

Recupera todas las filas restantes y devuelve una lista.

Ejemplo con fetchone():

cursor.execute("""
    SELECT *
    FROM estudiantes
    WHERE id_estudiante = ?
""", (1,))

estudiante = cursor.fetchone()

print(estudiante)

Este fragmento se ejecuta con una conexión y un cursor previamente creados.

Relación con estructuras de Python

[
    (1, "Ana", "Desarrollo de Software", 20),
    (2, "Carlos", "Redes Informáticas", 22)
]

Por defecto, fetchall() devuelve una lista de tuplas. Estos elementos pueden procesarse posteriormente mediante ciclos, condiciones y otras estructuras de datos de Python.

5.7. Actualización y eliminación de información

Las operaciones Update y Delete modifican la información almacenada mediante las instrucciones UPDATE y DELETE.

Actualización mediante SQL

UPDATE estudiantes
SET carrera = 'Ciberseguridad'
WHERE id_estudiante = 2;

Actualización mediante Python

import sqlite3

conexion = sqlite3.connect("universidad.db")
cursor = conexion.cursor()

cursor.execute("""
    UPDATE estudiantes
    SET carrera = ?
    WHERE id_estudiante = ?
""", ("Ciberseguridad", 2))

conexion.commit()

print("Registro actualizado")

conexion.close()

El primer parámetro establece la nueva carrera y el segundo identifica el registro.

Actualización mediante variables

id_estudiante = 2
nueva_carrera = "Ciberseguridad"

cursor.execute("""
    UPDATE estudiantes
    SET carrera = ?
    WHERE id_estudiante = ?
""", (nueva_carrera, id_estudiante))

Este fragmento requiere una conexión y cursor activos. Facilita utilizar datos provenientes de formularios u otras interfaces.

Eliminación mediante Python

import sqlite3

conexion = sqlite3.connect("universidad.db")
cursor = conexion.cursor()

cursor.execute("""
    DELETE FROM estudiantes
    WHERE id_estudiante = ?
""", (4,))

conexion.commit()

print("Operación de eliminación ejecutada")

conexion.close()

Si el registro existe, será eliminado. Si no existe, la ejecución puede finalizar sin error y sin eliminar filas.

Verificación con rowcount

cursor.execute("""
    DELETE FROM estudiantes
    WHERE id_estudiante = ?
""", (4,))

print("Registros eliminados:", cursor.rowcount)

conexion.commit()
Resultado si existía el registro 
Registros eliminados: 1
Precaución con las condiciones 
DELETE FROM estudiantes;

Sin WHERE, la instrucción elimina todas las filas de la tabla. También UPDATE puede modificar todos los registros si se omite la condición.

5.8. Gestión de conexiones, transacciones y confirmación de cambios

Una transacción es una unidad de trabajo que agrupa operaciones relacionadas y permite administrar sus cambios de manera coordinada.

commit()

Confirma los cambios pendientes de una transacción.

conexion.commit()
rollback()

Revierte los cambios no confirmados de una transacción.

conexion.rollback()

Ejemplo de transacción: transferencia de inventario

Un sistema necesita transferir cinco unidades del producto 101 desde el almacén 1 hacia el almacén 2. Se supone que la tabla inventario ya existe y contiene los registros de ambos almacenes.

import sqlite3

conexion = sqlite3.connect("inventario.db")

try:
    cursor = conexion.cursor()

    cursor.execute("""
        UPDATE inventario
        SET cantidad = cantidad - 5
        WHERE id_almacen = 1
        AND id_producto = 101
        AND cantidad >= 5
    """)

    if cursor.rowcount != 1:
        raise ValueError("Existencia insuficiente")

    cursor.execute("""
        UPDATE inventario
        SET cantidad = cantidad + 5
        WHERE id_almacen = 2
        AND id_producto = 101
    """)

    if cursor.rowcount != 1:
        raise ValueError("Almacén destino no encontrado")

    conexion.commit()
    print("Transferencia completada")

except (sqlite3.Error, ValueError) as error:
    conexion.rollback()
    print("Error:", error)

finally:
    conexion.close()

Explicación

  1. El bloque try ejecuta las operaciones.
  2. La primera instrucción descuenta cinco unidades del almacén de origen si existen suficientes.
  3. La segunda incorpora cinco unidades al almacén de destino.
  4. rowcount verifica que cada operación afecte un registro.
  5. commit() confirma los cambios cuando todo es correcto.
  6. rollback() revierte cambios pendientes ante errores.
  7. finally cierra la conexión.

El ejemplo utiliza el comportamiento transaccional habitual de sqlite3. El modo exacto de administración de transacciones depende de la configuración de la conexión.

Buenas prácticas

  • Cerrar las conexiones cuando ya no se necesitan.
  • Utilizar consultas parametrizadas.
  • Confirmar cambios correctos con commit().
  • Revertir cambios ante errores con rollback().
  • Aplicar restricciones de integridad.
  • Evitar actualizaciones y eliminaciones sin condiciones.
  • Verificar los resultados de las operaciones importantes.

Se desarrollará un sistema básico de estudiantes utilizando funciones de Python y SQLite.

Funcionalidades
  • Crear la base de datos y la tabla.
  • Registrar estudiantes.
  • Consultar estudiantes.
  • Actualizar carreras.
  • Eliminar registros.
  • Conservar información entre ejecuciones.

Paso 1. Importar el módulo

import sqlite3

Paso 2. Crear la base de datos y la tabla

def crear_base_datos():
    conexion = sqlite3.connect("estudiantes.db")

    conexion.execute("""
        CREATE TABLE IF NOT EXISTS estudiantes (
            id INTEGER PRIMARY KEY,
            nombre TEXT NOT NULL,
            carrera TEXT NOT NULL,
            edad INTEGER
        )
    """)

    conexion.commit()
    conexion.close()

La función crea la estructura si todavía no existe.

Paso 3. Registrar estudiantes

def registrar_estudiante(nombre, carrera, edad):
    conexion = sqlite3.connect("estudiantes.db")

    conexion.execute("""
        INSERT INTO estudiantes (nombre, carrera, edad)
        VALUES (?, ?, ?)
    """, (nombre, carrera, edad))

    conexion.commit()
    conexion.close()

Los datos se insertan mediante parámetros, evitando incorporar directamente los valores dentro del texto SQL.

Paso 4. Consultar estudiantes

def consultar_estudiantes():
    conexion = sqlite3.connect("estudiantes.db")

    registros = conexion.execute("""
        SELECT *
        FROM estudiantes
        ORDER BY id
    """).fetchall()

    for estudiante in registros:
        print(estudiante)

    conexion.close()

La función recupera registros ordenados por identificador y los recorre utilizando for.

Paso 5. Actualizar estudiantes

def actualizar_carrera(id_estudiante, nueva_carrera):
    conexion = sqlite3.connect("estudiantes.db")

    conexion.execute("""
        UPDATE estudiantes
        SET carrera = ?
        WHERE id = ?
    """, (nueva_carrera, id_estudiante))

    conexion.commit()
    conexion.close()

Paso 6. Eliminar estudiantes

def eliminar_estudiante(id_estudiante):
    conexion = sqlite3.connect("estudiantes.db")

    conexion.execute("""
        DELETE FROM estudiantes
        WHERE id = ?
    """, (id_estudiante,))

    conexion.commit()
    conexion.close()

Análisis de la implementación

Cada función implementa una responsabilidad: creación de tablas, inserción, consulta, actualización o eliminación. Python administra las instrucciones mientras SQLite conserva la información.

Los identificadores permiten seleccionar registros específicos, y las consultas devuelven datos que pueden procesarse mediante listas, tuplas y ciclos.

Nota: para obtener exactamente el resultado mostrado debe utilizarse una base inicialmente vacía. La ejecución repetida puede insertar nuevos registros y modificar los identificadores. Este ejemplo didáctico no incluye todas las validaciones y controles de errores de una aplicación de producción.

Síntesis del subtema

SQLite es un motor de bases de datos relacional que permite almacenar y administrar información mediante SQL sin requerir un servidor independiente.

Su integración con Python se realiza mediante el módulo sqlite3, que proporciona herramientas para establecer conexiones, ejecutar instrucciones y recuperar resultados.

La creación de tablas permite definir la organización lógica de los datos mediante campos, tipos y restricciones.

Las instrucciones INSERT, SELECT, UPDATE y DELETE permiten implementar las operaciones CRUD.

Las consultas parametrizadas contribuyen a realizar operaciones de manera segura, mientras que las transacciones permiten confirmar o revertir cambios.

Desde la perspectiva de las estructuras de datos, SQLite utiliza mecanismos internos de organización e indexación, mientras que Python permite procesar resultados mediante listas, tuplas, diccionarios y algoritmos.

La integración de ambas tecnologías permite desarrollar aplicaciones capaces de gestionar información estructurada y persistente, relacionando los fundamentos de las estructuras de datos con su aplicación en sistemas de bases de datos.
