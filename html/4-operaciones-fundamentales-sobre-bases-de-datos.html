Bases de datos como estructura de datos

Operaciones fundamentales sobre bases de datos

Comprender y aplicar las operaciones CRUD mediante SQL y su relación con las estructuras de datos de Python.

Objetivo de aprendizaje

Comprender y aplicar las operaciones fundamentales de manipulación de datos mediante el modelo CRUD, identificando las funciones de creación, consulta, actualización y eliminación de registros, así como su implementación mediante instrucciones SQL, para reconocer cómo las bases de datos permiten administrar información de manera estructurada y su relación con las operaciones utilizadas en las estructuras de datos de Python.

Introducción

Durante el desarrollo de aplicaciones informáticas, no es suficiente almacenar información de manera organizada. También es necesario realizar operaciones que permitan incorporar nuevos datos, recuperar registros existentes, modificar información y eliminar elementos que ya no sean necesarios.

Estas operaciones son fundamentales para el funcionamiento de sistemas académicos, comerciales, hospitalarios, financieros y administrativos.

En el estudio de las estructuras de datos, operaciones como insertar, buscar, modificar y eliminar elementos se implementan mediante métodos y algoritmos específicos.

Por ejemplo, una lista de Python permite agregar elementos utilizando append(), buscar valores mediante recorridos, actualizar posiciones mediante índices y eliminar elementos utilizando remove() o pop().

Las bases de datos presentan necesidades similares, pero incorporan mecanismos especializados para administrar registros persistentes y mantener la integridad de la información.

Uno de los conceptos más importantes es CRUD, que agrupa las operaciones de crear, leer, actualizar y eliminar. En el modelo relacional se implementan mediante instrucciones SQL.

4.1. Concepto de operaciones CRUD

CRUD proviene de las palabras inglesas Create, Read, Update y Delete, que representan las cuatro operaciones fundamentales para administrar registros.

C
Create - Crear

Incorporar nuevos registros mediante INSERT.

R
Read - Leer

Consultar información mediante SELECT.

U
Update - Actualizar

Modificar registros mediante UPDATE.

D
Delete - Eliminar

Retirar registros mediante DELETE.

Operaciones fundamentales

Operación Significado Función SQL
Create Crear Incorporar registros INSERT
Read Leer Consultar registros SELECT
Update Actualizar Modificar registros UPDATE
Delete Eliminar Retirar registros DELETE

Ejemplo: sistema de estudiantes

Una universidad utiliza las operaciones CRUD para registrar estudiantes, consultar matrículas, actualizar información académica y retirar registros autorizados.

Relación con estructuras de datos

CRUD Lista de Python Base de datos
Crear append() INSERT
Leer Índices o recorridos SELECT
Actualizar Asignación por índice UPDATE
Eliminar remove(), pop() DELETE

Las listas de Python suelen trabajar en memoria, mientras que una base de datos persistente permite conservar cambios confirmados e incorporar mecanismos de integridad y transacciones.

4.2. Creación de registros (Create)

La operación Create incorpora registros a una tabla mediante la instrucción INSERT.

Ejemplo: registro de estudiantes

Tabla antes de la inserción:

id_estudiante nombre carrera edad
1 Ana Martínez Desarrollo de Software 20
2 Carlos López Redes Informáticas 22

Sintaxis básica:

INSERT INTO nombre_tabla (campo1, campo2, campo3)
VALUES (valor1, valor2, valor3);

Inserción de María Hernández:

INSERT INTO estudiantes
(id_estudiante, nombre, carrera, edad)
VALUES
(3, 'María Hernández', 'Desarrollo de Software', 21);
Tabla después de la inserción
ID Nombre Carrera Edad
1 Ana Martínez Desarrollo de Software 20
2 Carlos López Redes Informáticas 22
3 María Hernández Desarrollo de Software 21

Explicación de la instrucción

  • INSERT INTO indica una inserción.
  • estudiantes identifica la tabla.
  • Los campos entre paréntesis indican las columnas.
  • VALUES contiene los valores correspondientes.

Relación con listas en Python

estudiantes = [
    {"id": 1, "nombre": "Ana"},
    {"id": 2, "nombre": "Carlos"}
]

nuevo_estudiante = {
    "id": 3,
    "nombre": "María"
}

estudiantes.append(nuevo_estudiante)

print(estudiantes)
Resultado 
[{'id': 1, 'nombre': 'Ana'}, {'id': 2, 'nombre': 'Carlos'}, {'id': 3, 'nombre': 'María'}]

El método append() agrega al final de una lista; INSERT crea una fila, sin asignarle una posición de orden garantizada.

Consideraciones

Antes de insertar se deben verificar tipos de datos, campos obligatorios, restricciones de unicidad y claves primarias. Un identificador declarado como clave primaria no puede duplicarse.

4.3. Consulta y recuperación de información (Read)

La operación Read recupera información almacenada mediante SELECT, seleccionando registros completos o aquellos que cumplen condiciones.

Tabla de referencia

ID Nombre Carrera Edad
1 Ana Martínez Desarrollo de Software 20
2 Carlos López Redes Informáticas 22
3 María Hernández Desarrollo de Software 21

Consultar todos los registros

SELECT *
FROM estudiantes;

El símbolo * indica que se recuperan todas las columnas.

Consultar campos específicos

SELECT nombre, carrera
FROM estudiantes;
Nombre Carrera
Ana Martínez Desarrollo de Software
Carlos López Redes Informáticas
María Hernández Desarrollo de Software

Consultar mediante WHERE

SELECT *
FROM estudiantes
WHERE carrera = 'Desarrollo de Software';

La consulta recupera a Ana Martínez y María Hernández, quienes pertenecen a Desarrollo de Software.

Operadores de comparación

Operador Significado Ejemplo
= Igual edad = 20
> Mayor edad > 20
< Menor edad < 25
>= Mayor o igual edad >= 18
<= Menor o igual edad <= 30
<> Diferente edad <> 20

Operadores lógicos AND, OR y NOT

SELECT *
FROM estudiantes
WHERE carrera = 'Desarrollo de Software'
AND edad >= 21;

Recupera estudiantes de Desarrollo de Software con edad mayor o igual a 21 años.

Ordenamiento con ORDER BY

SELECT *
FROM estudiantes
ORDER BY nombre ASC;

ASC representa orden ascendente y DESC orden descendente. Sin ORDER BY, SQL no garantiza un orden de filas.

Relación con búsquedas en Python

estudiantes = [
    {"id": 1, "nombre": "Ana", "edad": 20},
    {"id": 2, "nombre": "Carlos", "edad": 22},
    {"id": 3, "nombre": "María", "edad": 21}
]

for estudiante in estudiantes:
    if estudiante["edad"] > 20:
        print(estudiante["nombre"])
Resultado 
Carlos
María

El ciclo recorre la lista y evalúa una condición, de forma semejante al propósito de una consulta SQL. Un gestor puede usar recorridos o índices para ejecutar consultas.

Importancia de los índices

Los índices son estructuras auxiliares que pueden acelerar búsquedas. Algunos utilizan árboles B o B+, aunque su beneficio depende de los datos, la consulta y el diseño.

4.4. Actualización de registros (Update)

La operación Update modifica información almacenada mediante la instrucción UPDATE.

Por ejemplo, Carlos López cambia de Redes Informáticas a Ciberseguridad.

Sintaxis básica

UPDATE nombre_tabla
SET campo = nuevo_valor
WHERE condicion;

Actualización de carrera

UPDATE estudiantes
SET carrera = 'Ciberseguridad'
WHERE id_estudiante = 2;
ID Nombre Carrera actualizada
1 Ana Martínez Desarrollo de Software
2 Carlos López Ciberseguridad
3 María Hernández Desarrollo de Software

UPDATE identifica la tabla, SET establece el nuevo valor y WHERE selecciona los registros afectados.

Precaución: UPDATE sin WHERE 
UPDATE estudiantes
SET carrera = 'Ciberseguridad';

Esta instrucción actualiza todos los registros de la tabla porque no existe una condición que limite la operación.

Actualización de varios campos

UPDATE estudiantes
SET carrera = 'Ciberseguridad',
    edad = 23
WHERE id_estudiante = 2;

Relación con Python

estudiantes = [
    {"id": 1, "nombre": "Ana", "carrera": "Software"},
    {"id": 2, "nombre": "Carlos", "carrera": "Redes"}
]

for estudiante in estudiantes:
    if estudiante["id"] == 2:
        estudiante["carrera"] = "Ciberseguridad"

print(estudiantes)
Resultado 
[{'id': 1, 'nombre': 'Ana', 'carrera': 'Software'}, {'id': 2, 'nombre': 'Carlos', 'carrera': 'Ciberseguridad'}]

La asignación modifica el valor asociado a la clave del diccionario, una operación conceptualmente semejante a UPDATE.

4.5. Eliminación de registros (Delete)

La operación Delete retira registros mediante la instrucción DELETE, respetando las condiciones y reglas establecidas.

Ejemplo: eliminar un estudiante

DELETE FROM estudiantes
WHERE id_estudiante = 3;

Se elimina el registro de María Hernández, identificada con el código 3.

ID Nombre Carrera
1 Ana Martínez Desarrollo de Software
2 Carlos López Ciberseguridad
Precaución: DELETE sin WHERE 
DELETE FROM estudiantes;

Elimina todas las filas de la tabla. La tabla permanece creada, pero queda sin registros.

Relación con estructuras de datos en Python

estudiantes = ["Ana", "Carlos", "María"]

estudiantes.remove("María")

print(estudiantes)
Resultado 
['Ana', 'Carlos']

También puede eliminarse un registro de una lista de diccionarios mediante una condición:

estudiantes = [
    {"id": 1, "nombre": "Ana"},
    {"id": 2, "nombre": "Carlos"},
    {"id": 3, "nombre": "María"}
]

estudiantes = [
    estudiante
    for estudiante in estudiantes
    if estudiante["id"] != 3
]

print(estudiantes)
Resultado 
[{'id': 1, 'nombre': 'Ana'}, {'id': 2, 'nombre': 'Carlos'}]

Eliminación física y eliminación lógica

Eliminación física

El registro se retira de la tabla mediante una instrucción DELETE.

Eliminación lógica

El registro permanece almacenado, pero un campo indica que está inactivo.

Ejemplo de eliminación lógica en una tabla con el campo activo:

ID Nombre Activo
1 Ana Martínez 1
2 Carlos López 1
3 María Hernández 0 
UPDATE estudiantes
SET activo = 0
WHERE id_estudiante = 3;

El valor 0 indica que el registro se encuentra inactivo. Este enfoque puede servir para conservar información histórica según las políticas del sistema.

4.6. Introducción al lenguaje SQL

SQL (Structured Query Language) es un lenguaje utilizado para definir, consultar y manipular información en sistemas de bases de datos relacionales.

SQL es principalmente declarativo: permite especificar los resultados deseados y el gestor determina cómo realizar muchas de las operaciones.

Categorías principales de SQL

Categoría Nombre Función Ejemplos
DDL Data Definition Language Definir estructuras CREATE, ALTER, DROP
DML Data Manipulation Language Manipular registros INSERT, UPDATE, DELETE
DQL Data Query Language Consultar datos SELECT
DCL Data Control Language Gestionar permisos GRANT, REVOKE
TCL Transaction Control Language Controlar transacciones COMMIT, ROLLBACK

La clasificación es didáctica y depende del gestor. SQLite no incorpora GRANT y REVOKE como instrucciones propias para administrar permisos de usuarios.

Ejemplo completo del ciclo CRUD

Crear la tabla:

CREATE TABLE estudiantes (
    id_estudiante INTEGER PRIMARY KEY,
    nombre TEXT NOT NULL,
    carrera TEXT NOT NULL,
    edad INTEGER
);

La instrucción define cuatro campos, una clave primaria y dos campos obligatorios.

Insertar información:

INSERT INTO estudiantes
(id_estudiante, nombre, carrera, edad)
VALUES
(1, 'Ana Martínez', 'Desarrollo de Software', 20);

Consultar información:

SELECT *
FROM estudiantes;

Actualizar información:

UPDATE estudiantes
SET edad = 21
WHERE id_estudiante = 1;

Eliminar información:

DELETE FROM estudiantes
WHERE id_estudiante = 1;

El conjunto muestra las operaciones CRUD sobre la misma tabla. La creación de la estructura mediante CREATE TABLE corresponde a DDL y es distinta de la creación de registros mediante INSERT.

4.7. Importancia de las operaciones CRUD en la administración de datos

CRUD constituye la base de muchas funcionalidades: registrar datos, consultar información, actualizar formularios y eliminar registros de acuerdo con las reglas de cada sistema.

Integración en aplicaciones reales

Aplicación Create Read Update Delete
Académico Registrar estudiante Consultar matrícula Modificar carrera Retirar registro autorizado
Inventario Agregar producto Consultar existencia Actualizar cantidad Retirar producto
Biblioteca Registrar préstamo Consultar préstamos Actualizar devolución Eliminar si está permitido
Comercio electrónico Crear pedido Consultar compras Actualizar estado Cancelar según reglas
Tickets Crear solicitud Consultar estado Modificar prioridad Eliminar si está permitido

Integridad de los datos

Las operaciones deben respetar restricciones. Por ejemplo, una matrícula no debería relacionarse con un estudiante inexistente cuando existen claves foráneas activas.

Transacciones

Una transacción es una unidad de trabajo compuesta por una o varias operaciones que deben coordinarse para mantener la consistencia de la información.

COMMIT

Confirma los cambios realizados durante una transacción.

ROLLBACK

Revierte los cambios no confirmados de una transacción.

Caso: venta en un inventario

  1. Registrar la venta de dos teclados.
  2. Disminuir en dos unidades la existencia.
  3. Confirmar ambas operaciones si resultaron correctamente.
  4. Revertir la transacción si alguna operación falla.

Seguridad en las operaciones

Al ejecutar SQL desde Python se recomienda utilizar consultas parametrizadas en lugar de concatenar directamente los datos recibidos de usuarios.

cursor.execute(
    "SELECT * FROM estudiantes WHERE id_estudiante = ?",
    (id_estudiante,)
)

El símbolo ? representa un parámetro cuyo valor se proporciona separadamente de la instrucción SQL. Esto contribuye a prevenir inyecciones SQL cuando se utiliza correctamente.

Relación entre CRUD y eficiencia

Cantidad de registros

El volumen de datos puede influir en los tiempos de procesamiento.

Estructuras e índices

Pueden facilitar búsquedas y requerir mantenimiento.

Condiciones y transacciones

Influyen en los registros afectados y las garantías de consistencia.

Los índices pueden acelerar consultas, pero también generan costos al insertarse, modificarse o eliminarse registros. La eficiencia depende del diseño, del volumen de información y de los algoritmos utilizados por el gestor.

Síntesis del subtema

Las operaciones CRUD constituyen un modelo fundamental para administrar información mediante las acciones de creación, lectura, actualización y eliminación.

En las bases de datos relacionales se realizan principalmente mediante las instrucciones SQL INSERT, SELECT, UPDATE y DELETE.

Estas operaciones se relacionan conceptualmente con los métodos de inserción, acceso, modificación y eliminación utilizados en listas y diccionarios de Python.

Los sistemas gestores incorporan mecanismos adicionales para mantener información persistente, aplicar restricciones de integridad y administrar transacciones.

El uso correcto de SQL requiere comprender las condiciones de búsqueda, la identificación de registros y los riesgos asociados con modificaciones o eliminaciones sin criterios específicos.

Finalmente, el rendimiento de CRUD depende de las estructuras de almacenamiento, índices, algoritmos, cantidad de registros y mecanismos de transacción. Su comprensión establece las bases para implementar sistemas de gestión mediante Python y SQLite.
